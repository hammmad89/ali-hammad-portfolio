# Ali Hammad — Data Analytics Portfolio

A responsive, dark-tech personal portfolio for GitHub Pages. Built with plain HTML, CSS, and JavaScript (no build step or external JS dependencies).

## Files
- `index.html` — page content
- `styles.css` — responsive dark charcoal / electric blue design
- `script.js` — mobile navigation and current footer year
- `Ali_Hammad_CV.docx` — editable CV download link used on the site
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## Publish with GitHub Pages

1. Sign in to GitHub as the account that owns the project repositories.
2. Create a **new public repository** named `ali-hammad-portfolio`.
3. Upload all files in this folder to the repository's root (not the parent folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the Pages deployment to complete. Under Settings → Pages, click **Visit site**.

Expected project-site URL (if the GitHub username is `hammmad89`):
`https://hammmad89.github.io/ali-hammad-portfolio/`

GitHub Pages may take several minutes to publish. If the expected URL differs, use the exact URL displayed in Settings → Pages.

## Before publishing
- Check that the CV download file is present in the repository root and is named exactly `Ali_Hammad_CV.docx`.
- Verify the education titles, employment details, dates, and listed skills before making the site public.
- The chart in the hero area is decorative and explicitly labelled illustrative; it is not a real business result.
- The Retail Intelligence Lab live dashboard link has intentionally not been invented. Add it in `index.html` after deploying the dashboard.
- This website is public. Do not upload private or sensitive information.

## Update the site
Edit `index.html` or `styles.css` in GitHub, commit changes to `main`, and GitHub Pages will republish the site.
